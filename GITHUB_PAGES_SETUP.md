# 🌐 GitHub Pages Setup for MMM Dashboard

Your GitHub-shareable MMM Dashboard is ready! Follow these steps to enable GitHub Pages:

## 🚀 Enable GitHub Pages (One-Time Setup)

1. **Go to your GitHub repository:**
   - Visit: https://github.com/NeVoTM/nevo-tower-portal

2. **Navigate to Settings:**
   - Click on "Settings" tab in your repository

3. **Find Pages section:**
   - Scroll down to "Pages" in the left sidebar
   - Click on "Pages"

4. **Configure Source:**
   - Under "Source", select "Deploy from a branch"
   - Choose "main" branch
   - Choose "/docs" folder
   - Click "Save"

5. **Wait for deployment:**
   - GitHub will show "Your site is ready to be published at..."
   - It may take a few minutes to become available

## 🔗 Your Dashboard URLs

Once GitHub Pages is enabled, your dashboard will be available at:

- **Main Dashboard:** https://nevotm.github.io/nevo-tower-portal/mmm-dashboard.html
- **Auto-redirect:** https://nevotm.github.io/nevo-tower-portal/

## 🔄 Updating Your Dashboard

To update with fresh Google Sheets data:

### From Windows (Local):
```bash
cd C:\Users\user\Documents\GitHub\nevo-tower-portal\MMM
node generate-shareable-dashboard.js
```

### From Codespace:
```bash
cd /workspaces/nevo-tower-portal/MMM
node generate-shareable-dashboard.js
```
