This repository contains a comprehensive **Miami Makers Model (MMM)** presentation and analysis system, featuring:

- **📈 Real Project Data Integration** using Roy Abrams' actual $158.9M development

### Business Model: "Partners Not Paychecks, Partners Not Investors"
Transform traditional real estate development by converting service providers (contractors, architects, engineers, legal) into **equity partners** instead of paying cash fees.

## 🚀 **GETTING STARTED**

### Local Development
```bash
# Navigate to project
cd nevo-tower-portal

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the AI agent interface.

### Environment Variables Required
```bash
GEMINI_API_KEY=your_google_gemini_key
ANTHROPIC_API_KEY=your_anthropic_claude_key
```
